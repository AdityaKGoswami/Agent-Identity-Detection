# Agent Identity Detection

A research and experimental project for detecting identity and behavioral anomalies in AI agent sessions.

This repository contains the complete project structure, including:

- Agent harness and simulated agent workflows
- Detection and classification components
- Synthetic and combined datasets
- Batch testing and evaluation
- Error analysis
- Experimental results and dataset comparisons

## Project Structure

```
agent_harness/   Agent simulation and harness components
src/             Detection, classification, evaluation and analysis
data/            Project datasets
results/         Experimental outputs and metrics
```

## Installation

```bash
pip install -r requirements.txt
```

See the project documentation and source files for individual experiment workflows.
